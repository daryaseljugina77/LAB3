# Лабораторная работа № 3

Реализация, тестирование и анализ производительности структур данных на языке C++.

## Реализованные структуры данных

- Динамический массив (Array)
- Односвязный список (FList)
- Двусвязный список (DList)
- Стек (Stack)
- Очередь (Queue)
- Хеш-таблица методом цепочек (ChainHash)
- Хеш-таблица с кукушкиным хешированием (CuckooHash)
- Полное бинарное дерево (CompleteTree)

Для структур данных реализованы основные операции, а также сериализация и десериализация в текстовом и бинарном форматах.

## Сборка проекта

Для сборки используются CMake и компилятор с поддержкой C++17.

```bash
cmake -S . -B build
cmake --build build
```

## Запуск программы

```bash
./build/main
```

## Автоматическое тестирование

Для тестирования используется Google Test.

```bash
./build/google_test
```

Результаты тестирования:
- Выполнено 93 теста.
- Покрытие строк — 88,7%.
- Покрытие функций — 93,9%.

Для измерения покрытия использовались gcov и LCOV.

## Измерение производительности

Измерение производительности реализовано с помощью Google Benchmark.

Запуск:

```bash
./build/benchmark_test
```

Результаты измерений сохранены в файле `benchmark_results.csv`.
