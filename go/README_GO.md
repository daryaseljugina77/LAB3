# Лабораторная работа № 3 — Go

Многофайловая реализация тех же восьми структур данных, что и в проекте на C++: массив, односвязный и двусвязный списки, стек, очередь, хеш-таблица с цепочками, кукушкино хеширование и полное бинарное дерево.

Все файлы `.go` находятся в одном пакете `main`, но каждая структура выделена в отдельный файл. Консольный интерфейс (`main.go`) поддерживает выбор структуры, выполнение операций, сохранение и загрузку данных в текстовом и бинарном форматах. Названия команд соответствуют консольной версии C++.

## Запуск

```bash
cd ~/LAB3/go
go run .
```

## Тестирование и покрытие

```bash
go test ./...
go test -coverprofile=coverage.out ./...
go tool cover -func=coverage.out
go tool cover -html=coverage.out -o coverage.html
```

При контрольном запуске в Go 1.23.2 пройдены тесты, суммарное покрытие операторов — **87,9%**. При изменениях кода и тестов показатель нужно пересчитывать.

## Benchmark и статический анализ

```bash
go test -run '^$' -bench . -benchmem -benchtime=100ms
go vet ./...
gofmt -l .
```

Сохранённые данные создаются в рабочем каталоге (`array.txt`, `array.bin` и т. д.). Запускайте Go-программу из `go/`, чтобы не смешивать их с файлами C++.

Тесты используют стандартный пакет `testing`; внешняя библиотека `testify` пока не подключена.
